# 📊 Sales Data Analysis using Python

## 📌 Project Overview

This project analyzes sales data from the Superstore dataset using **Python**, **Pandas**, **Matplotlib**, and **Seaborn**.

The objective is to explore the dataset, identify sales trends, compare category-wise performance, analyze regional sales, and discover the best-selling products through data visualization.

This project demonstrates the fundamentals of Data Analysis, Data Exploration, and Data Visualization.

---

## 🎯 Objectives

- Explore and understand the dataset
- Perform basic data cleaning and inspection
- Analyze monthly sales trends
- Compare sales across product categories
- Analyze category-wise profit
- Compare sales across different regions
- Identify the Top 10 best-selling products
- Visualize insights using charts

---

## 🛠 Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn

## 📌 Key Insights

- Technology generated the highest overall profit.
- West region recorded the highest sales.
- Sales were highest during November and December.
- Office Supplies had strong sales volume.
- A few premium products contributed significantly to total revenue.

## 🚀 How to Run

### 1. Clone the repository



### 3. Install dependencies

